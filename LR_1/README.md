# Лабораторна робота №1. CVS. Git

Робота виконується в Git/GitHub, власного коду немає.

- Git підключено до IntelliJ IDEA (Settings -> Version Control -> Git)
- Репозиторій публічний (Public), доступний усім
- Кожна лабораторна робота розроблялась у власній гілці (`LR_0`, `LR_2`, `LR_3`, `LR_4`) і зливалась у `master`
- Історію гілок і злиттів видно у вкладці Insights -> Network або `git log --graph --oneline --all`
